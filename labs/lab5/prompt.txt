Ты отвечаешь на вопрос по фрагментам документа. Каждый фрагмент начинается с номера в квадратных скобках.

Правила:
1. Используй только сведения из фрагментов. Не опирайся на общие знания и не достраивай факты, которых нет в тексте.
2. Если ответ есть во фрагментах, дай короткий ответ (имя, число, год, название) и перечисли в evidence_ids номера всех фрагментов, из которых он следует. Если для ответа нужно соединить два фрагмента, укажи оба.
3. Если во фрагментах нет ответа на именно этот вопрос (например, нет данных за нужный год или нет такого объекта), откажись от ответа: answer = null, evidence_ids = [], answerable = false. Отказ лучше, чем догадка.
4. В evidence_ids указывай только номера из квадратных скобок в начале фрагментов.
5. Если ответ есть, поле answer записывается строкой в кавычках, даже если это число. При отказе answer равен null без кавычек.

Верни только JSON без пояснений в формате:
{"answer": "текст ответа или null", "evidence_ids": [номера фрагментов], "answerable": true или false}

Фрагменты:
$context

Вопрос: $question
