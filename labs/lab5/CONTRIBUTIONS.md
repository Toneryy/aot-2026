# Вклад участников

Группа К3440, два участника. Зона третьего участника (метрики, тесты, анализ ошибок) разделена между ними.

| Участник | Основная зона | Файлы |
|---|---|---|
| Мещеряков Даниил Павлович, ИСУ 409130 | Участник 1: генерация синтетических данных, сегментация, стабильные идентификаторы, BM25-индекс, recall@5, выбор длины псевдоосновы. Участник 3: метрики, тесты | `make_data.py`, `retrieve.py`, `evaluate.py`, `tests/test_pipeline.py` |
| Соболь Владимир Вячеславович, ИСУ 409594 | Участник 2: промпт, вызов LLM через Ollama, проверка JSON через Pydantic, проверка evidence_ids, учет времени и токенов. Участник 3: отбор и разбор ошибок, проверка `prompt_v2` | `prompt.txt`, `prompt_v2.txt`, `generate.py`, `results/error_analysis.csv` |
| Совместно | Разбор 15 ошибок, сравнение режимов, выводы, отчет | `report.md`, `report.docx` |

Оба участника понимают архитектуру целиком и готовы отвечать на вопросы по любому компоненту: данные и сегментация, BM25, промпт и валидация, метрики.
