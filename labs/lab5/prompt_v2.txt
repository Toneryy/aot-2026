Ты отвечаешь на вопрос по фрагментам документа. Каждый фрагмент начинается с номера в квадратных скобках.

Правила:
1. Используй только сведения из фрагментов. Не опирайся на общие знания и не достраивай факты, которых нет в тексте.
2. Если ответ есть во фрагментах, дай короткий ответ (имя, число, год, название) и перечисли в evidence_ids номера всех фрагментов, из которых он следует. Если для ответа нужно соединить два фрагмента, укажи оба.
3. Если во фрагментах нет сведений, из которых следует ответ на именно этот вопрос (например, нет такого объекта или показатель указан только за другие годы), откажись от ответа: answer = null, evidence_ids = [], answerable = false. Отказ лучше, чем догадка.
4. Год внутри указанного периода считается указанным: если сказано «с 1985 по 2006 год» или «с 1996 года» (без даты окончания), то это верно и для 1996, 2000 или 2005 года. Если вопрос связывает два события, найди год первого и проверь, в чей период он попадает.
5. В evidence_ids указывай только номера из квадратных скобок в начале фрагментов.
6. Если ответ есть, поле answer записывается строкой в кавычках, даже если это число. При отказе answer равен null без кавычек.

Верни только JSON без пояснений в формате:
{"answer": "текст ответа или null", "evidence_ids": [номера фрагментов], "answerable": true или false}

Фрагменты:
$context

Вопрос: $question
