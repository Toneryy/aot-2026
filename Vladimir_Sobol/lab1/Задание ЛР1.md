# Лабораторная работа №1

Лабораторная работа №1. Один текст — разные представления

Курс: Автоматическая обработка текстов

**Цель**

Исследовать, какие свойства текста сохраняются и теряются при переходе от текста к вычислительному представлению.

**Исходные данные**

Используйте выборку из 100–200 русскоязычных текстов RuSentiment [https://github.com/text-machine-lab/rusentiment](https://github.com/text-machine-lab/rusentiment) 

Столбцы файла: id, text, label.

**Задание (индивидуально)**

1. Загрузите данные и проверьте пропуски, дубликаты и распределение длин текстов.   
2. Постройте четыре представления: набор поверхностных признаков; bag-of-words; TF–IDF; sentence embeddings.  
3. Выберите три исходных текста разных классов. Для каждого создайте три варианта: перестановка слов или предложений без намеренного изменения смысла; парафраз; изменение смыслообразующего элемента, например добавление или удаление отрицания.  
4. Вычислите косинусное сходство исходного и измененного текста для bag-of-words, TF–IDF и embeddings.  
5. Для каждого преобразования вручную укажите, изменился ли, по вашему мнению, смысл текста. Кратко обоснуйте решение.  
6. Сделайте вывод: какие изменения видит каждое представление и какие изменения оно игнорирует.

**Технологический минимум**

* Python;  
* pandas;  
* scikit-learn: CountVectorizer, TfidfVectorizer, cosine\_similarity;  
* razdel;  
* sentence-transformers;  
* matplotlib или seaborn.

**Обязательные результаты**

1. таблица из девяти сравнений: три текста × три преобразования;  
2. распределение длин текстов;  
3. визуализация сходства исходных и изменённых текстов;  
4. не менее трёх примеров, в которых численная близость плохо согласуется с изменением смысла.

**Что сдаётся**

1. notebook с последовательным запуском;  
2. CSV с девятью преобразованными текстами;  
3. отчёт объёмом 700–1 000 слов.
