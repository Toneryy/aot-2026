# Лабораторная работа №3

Лабораторная работа №3. Классика против LLM

Курс: Автоматическая обработка текстов

 

**Цель**

Сравнить классический признаковый классификатор и генеративную языковую модель не только по качеству, но и по устойчивости, времени и стоимости обработки.

**Исходные данные**

Используйте подготовленную версию RuSentiment: 3 000 объектов train, 500 validation и 500 test. Классы: positive, negative, neutral. Сгенерировать с помощью LLM синтетически: стресс-набор из 100 примеров с отрицанием, опечатками, иронией, цитированием и смешанной оценкой.

**Задание (индивидуально)**

1. Постройте baseline, всегда предсказывающий наиболее частый класс.  
2. Постройте Pipeline: TfidfVectorizer с word n-граммами 1–2 и LogisticRegression. Допускается изменить не более двух гиперпараметров на validation.  
3. Реализуйте zero-shot классификацию одной LLM. Требуйте ответ в JSON с единственным полем label.  
4. Реализуйте few-shot вариант той же LLM с шестью примерами: по два примера каждого класса.  
5. Оцените четыре режима на основном test и стресс-наборе.  
6. Измерьте среднее время обработки одного текста. Для LLM дополнительно зафиксируйте число входных и выходных токенов и оцените стоимость 1 000 текстов, если модель тарифицируется.  
7. Разберите 15 ошибок: пять классического метода, пять LLM и пять случаев их расхождения.  
8. Рекомендуйте решение для массовой обработки, небольшого потока сложных текстов и локальной обработки без внешнего API.

**Обязательный формат ответа LLM**

{  
  "label": "positive | negative | neutral"  
}

**Технологический минимум**

* pandas;  
* scikit-learn;  
* одна LLM через согласованный интерфейс;  
* pydantic;  
* time или timeit;  
* токенизатор выбранной модели.

**Что сдаётся**

1. notebook или Python-скрипт;  
2. два промпта;  
3. CSV с предсказаниями всех методов;  
4. таблица метрик, времени и стоимости;  
5. отчет.
